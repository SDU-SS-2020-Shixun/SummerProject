##后端接口文档

1. /imgProcess/upload

接口描述：接收上传的验证码图片，转换成为png格式到本地，调用模型的接口，实现验证码的识别，最终返回识别的结果

请求参数：[
    "img": 图片文件
]

返回参数：[

    "code": 200,表示返回成功;400,表示返回失败
    
    "imgCode": 验证码结果，为str类型
]

2. /imgProcess/createImg

接口描述：请求该接口后，生成随机一张验证码图片，之后返回图片的路径以及验证码的值

请求参数：无

返回参数：[

    "code": 200,创建成功
    
    "img": 图片文件的路径，相对路径
    
    "imgCode": 验证码的实际值
    
]
